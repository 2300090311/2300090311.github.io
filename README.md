# Shubhra Kumari — Portfolio

A responsive, single-page portfolio website built with plain HTML and CSS.

## Preview locally
1. Extract the ZIP file.
2. Open the `shubhra_portfolio` folder in VS Code.
3. Open `index.html` in a browser (or use the VS Code Live Server extension).

## Before publishing
- Confirm that the CGPA, education dates, certification names, and project descriptions are accurate.
- Add your GitHub URL and project/demo links when available.
- Add a downloadable resume link if you want one on the page.

## Publish free with GitHub Pages
1. Keep `profile.jpg` in the same repository folder as `index.html` and `style.css`.
2. Create a GitHub repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
3. Upload `index.html`, `style.css`, `profile.jpg`, and `README.md` to the repository's root.
4. In repository Settings → Pages, enable deployment from the `main` branch and `/ (root)`.
5. Your site will be available at `https://yourusername.github.io/` after GitHub Pages finishes publishing.


## Add your resume
Place your latest resume PDF in this same folder and name it exactly `resume.pdf`.
The Download Resume button on the homepage will then download it.

## Add project repository links
When each project repository is available on GitHub, replace the corresponding
"GitHub repository link to be added" text in `index.html` with a link to that
specific repository. Do not link a project card to your general profile as if
it were the project source.
